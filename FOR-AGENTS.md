# FOR-AGENTS.md — AI Agent Setup Guide

> This file is intended for AI coding assistants (Claude Code, Codex, Cursor, etc.)
> to help users install and configure customclaw on their local machine.

## Prerequisites Check

Before starting, verify:

1. **Docker & Docker Compose** — `docker compose version` must work
2. **Python 3.12+** — `python3 --version` (for setup.py only; app runs in containers)
3. **Claude CLI** — `claude --version` (required for `claude` provider bots)
   - Install: `npm install -g @anthropic-ai/claude-code`
   - Auth: run `claude` once to complete OAuth login
4. **Codex CLI** (optional) — `codex --version` (for `codex` provider bots)
   - Install: `npm install -g @openai/codex`

## Installation Steps

### Step 1: Clone and Setup

```bash
git clone https://github.com/baekenough/customclaw.git
cd customclaw
python3 setup.py
```

`setup.py` is an interactive CLI (stdlib-only, no pip install needed) that:
1. Prompts for all required environment variables
2. Generates `.env` with your configuration
3. Optionally creates your first bot YAML
4. Optionally starts Docker services

### Step 2: Manual Setup (if setup.py is skipped)

```bash
cp .env.example .env
# Edit .env with required values (see Environment Variables below)
docker compose up -d
```

### Step 3: Verify

```bash
docker compose ps          # All services should be "Up" / "healthy"
docker compose logs worker  # Should show "Worker started. Consuming from..."
```

## Creating a Bot

Bots are YAML files in `bots/`. See `bots/example.yaml` for the full schema.

Minimal bot:

```yaml
name: my-bot
slack:
  app_token: ${MY_BOT_APP_TOKEN}
  bot_token: ${MY_BOT_BOT_TOKEN}
persona:
  display_name: "My Bot"
  personality: "You are a helpful assistant."
claude:
  provider: claude
  model: sonnet
  max_turns: 5
```

### Slack App Setup

1. Go to https://api.slack.com/apps → Create New App → From scratch
2. Enable Socket Mode → generate App-Level Token (`xapp-...`)
3. OAuth & Permissions → add scopes: `chat:write`, `reactions:write`, `reactions:read`, `channels:history`, `channels:read`
4. Install to Workspace → copy Bot Token (`xoxb-...`)
5. Event Subscriptions → subscribe to `message.channels`

## Adding Airflow DAGs

Place `.py` DAG files in `dags/`. They are auto-loaded via volume mount.

Example: `dags/example_hello_world.py` (included in repo)

## Architecture Quick Reference

```
Slack → slack-bolt → Redis Stream → worker → Claude/Codex CLI → Slack response
                                  → analysis_worker → GitHub comments + Slack notifications

PostgreSQL: messages, memories, bots, api_usage_logs
OpenSearch: keyword search index
Redis: message queue + analysis request stream
Airflow: scheduled DAGs (release monitoring, codebase indexing, etc.)
Web UI (Next.js): http://localhost:3000 — dashboard, bot management, monitoring
```

## Container Registry & Auto-update

| Aspect | Detail |
|--------|--------|
| Registry | GHCR (`ghcr.io/baekenough/customclaw-*`) |
| Image naming | `customclaw-slack-bolt` (shared by slack-bolt, worker, git-worker), `customclaw-web-ui`, `customclaw-airflow`, `customclaw-opensearch` |
| Auto-update | Watchtower (nickfedor/watchtower fork) checks for new images daily at 4:00 AM |
| Override pattern | `docker-compose.override.yml` for local development (build from source) |

- Production containers pull pre-built images from GHCR
- User data (`bots/`, `.env`, `dags/`) is volume-mounted and unaffected by image updates
- To pin a version: replace `latest` tag with a specific version (e.g., `v1.2.3`) in `docker-compose.yml`
- For local development: copy `docker-compose.override.yml.example` to `docker-compose.override.yml` to build from source instead of pulling GHCR images

## Common Operations

```bash
# Restart a specific service
docker compose restart worker

# Rebuild after code changes
docker compose build worker web-ui
docker compose up -d worker web-ui

# View logs
docker compose logs -f worker --since 5m

# Trigger an Airflow DAG manually
docker compose exec airflow airflow dags trigger <dag_id>

# Access PostgreSQL
docker compose exec postgres psql -U customclaw -d customclaw
```

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| Worker exits immediately | Missing `.env` variables | Check `docker compose logs worker` |
| Claude CLI not found | Binary not mounted | Verify `CLAUDE_CLI_BINARY` path in `.env` |
| Slack bot not responding | App token invalid | Regenerate Socket Mode token |
| Web UI 401 | NextAuth misconfigured | Check `NEXTAUTH_URL`, `NEXTAUTH_SECRET` |
| Airflow DAG not visible | File not in `dags/` | Check volume mount, run `airflow dags reserialize` |
